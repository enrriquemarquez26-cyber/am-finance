# Balance One — Android nativo
Base de desarrollo Kotlin/Compose/Room. No es aún la versión completa de Balance One.
Abrir esta carpeta en Android Studio. JDK 17, SDK 35, Gradle 8.9.
Con Gradle 8.9 instalado: `gradle :app:assembleDebug`. APK de prueba: app/build/outputs/apk/debug/app-debug.apk.
No hay wrapper binario incluido todavía. Ver CONTINUIDAD.md antes de continuar.
